# Build Guide Prompt

Create a practical Path of Exile 2 build guide for:

- Build name:
- Class:
- Tier:
- Playstyle:
- Difficulty:
- Patch or source context:

Follow this structure:

1. SEO title under 60 characters.
2. Meta description under 155 characters.
3. One-paragraph summary for players deciding whether to use the build.
4. Overview with class, tier, playstyle, and difficulty.
5. Strengths with specific player benefits.
6. Weaknesses with real tradeoffs.
7. Core skills and what each skill does in the build.
8. Recommended gear priorities, avoiding fake item names or exact values unless verified.
9. Leveling tips for early, mid, and late campaign.
10. Endgame notes for mapping and bossing.
11. FAQ with 4-6 search-focused questions.
12. Internal linking ideas to builds, bosses, and skills.

Rules:

- Be accurate, structured, and non-fluffy.
- Give practical advice a player can act on.
- Use SEO-friendly headings without keyword stuffing.
- If game data is not verified, clearly say what is uncertain.
- Do not invent patch changes, drop rates, DPS numbers, or hidden mechanics.
- Include reasons behind recommendations.
